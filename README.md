# SDIR 0.1 Preview

Windows용 다중 패널 파일 관리자입니다. Rust + Dioxus Desktop으로 만들었으며, Q-Dir의 다중 패널 사용성을 참고하고 goz-core를 내장 검색 엔진으로 사용합니다. Q-Dir 실행 파일이나 MTT 앱 코드를 복사하지 않았습니다.

최신 구현·여정 테스트·실측과 미확인 환경은 [검증 요약](docs/test-summary.md)을 확인하세요.

## 실행

`dist/SDIR-windows-x64-portable.zip`을 풀고 `SDIR.exe`를 실행합니다. `Start-SDIR.cmd`로 WebView2 설치 여부를 먼저 확인할 수도 있습니다. 파일 탐색과 현재 폴더 검색에는 별도 검색 프로그램이나 관리자 권한이 필요하지 않습니다. Windows 10/11 x64, Microsoft Edge WebView2 Runtime이 필요합니다. 앱은 Windows 서비스나 시작 프로그램을 등록하지 않습니다.

ZIP에는 `portable.flag`가 있으며 설정과 WebView 데이터는 실행 파일 옆 `data` 폴더에 저장합니다. 앱 폴더 전체를 옮기면 설정도 함께 이동합니다. 기존 SDIR 설정이 있으면 첫 실행에서 설정만 가져오고 원본은 보존합니다. 플래그 없는 기존 `dist/SDIR.exe`는 `%LOCALAPPDATA%\SDIR`을 계속 사용합니다. 개발·검증용 `SDIR_PROFILE_DIR` 환경 변수가 두 방식보다 우선합니다. 업데이트할 때는 앱 종료 후 실행 파일·문서를 교체하고 `data`를 보존합니다. [배포 방식 안내](docs/distribution.md)를 참고하세요.

## 현재 기능

- 드라이브·하위 폴더 트리: 필요한 단계만 비동기 조회, 현재 탭 경로 따라가기, 펼침 상태 복원과 키보드 순회
- 마우스 측면 뒤로/앞으로(X1/X2): 포인터 아래 패널의 탐색 이력 사용
- 현재 패널의 강조 테두리·헤더·텍스트 배지; 클릭·Tab·F6 초점 이동과 작업 대상 동기화
- 1·2·4분할 탐색, 패널별 최대 16개 탭, 뒤로·앞으로·상위 폴더 이동
- 최대 16개 작업공간 저장·전환: 분할, 그룹 이름, 탭 경로, 보기 방식, 활성 탭·패널을 함께 보관
- 닫은 탭 복원과 탭 단축키; 닫은 탭 기록은 패널별 최대 16개이며 목록 메모리는 해제
- 패널별 자세히·목록·큰 아이콘 보기, 열 표시·너비·아이콘 타일 크기 설정과 복원
- 탭 우클릭 고정·고정 해제·좌우 순서 변경; 고정 탭 닫기 방지
- 현재 열린 폴더의 외부 생성·수정·삭제·이름 변경 자동 반영, 선택·스크롤·입력 포커스 보존
- 기본 우클릭 메뉴와 연결 프로그램, 전체 경로 복사, 현재 폴더의 PowerShell 터미널
- 충돌 검사와 미리보기를 갖춘 파일·폴더 이름 일괄 변경
- 이번 실행의 작업 기록·항목별 결과·미완료 항목 재시도, 외부 Windows 앱으로 파일 복사 드래그
- 주소창 폴더 아이콘의 상위 경로 메뉴, 선택 반전(Ctrl+I), 복사·잘라내기 시각 표시
- 패널 위의 그룹 이름 편집: 업무용·제안용·개발용 등으로 지정하고 각 그룹에 폴더 탭 배치
- 설정: 시스템/밝게/어둡게 테마, 촘촘한/여유 있는 목록 간격, 숨김 파일 표시
- 즐겨찾기, 폴더 내부 이름 필터, 이름·크기·수정일 정렬, 숨김 파일 표시
- 화면에 필요한 행만 만드는 가상 목록, 패널별 독립적인 폴더 읽기와 취소
- 앱에서 수행한 지원 작업의 실행 취소·다시 실행(Ctrl+Z/Y), Windows 속성(Alt+Enter)
- Windows 기본 파일 작업: 새 폴더, 이름 변경, 복사·잘라내기·붙여넣기, 패널·탭을 지정한 복사, 휴지통 이동
- 앱 내장 검색: 현재 폴더와 하위 폴더를 명시적으로 색인한 뒤 파일명·경로·`ext:txt`·와일드카드 검색
- 통합 검색창의 왼쪽 경계를 끌어 너비를 조절하고, 확대 버튼으로 작업 영역을 넓게 사용
- 검색 결과는 현재 패널 또는 지정한 패널의 열린 탭에서 해당 위치를 열고 항목 선택

**현재 작업 대상 패널**은 강조 테두리와 헤더의 **현재 패널** 배지로 표시합니다. 하단에서도 현재 패널 번호를 확인할 수 있고, 번호에 마우스를 올리면 그룹 이름·전체 경로가 표시됩니다. 다른 패널을 클릭하거나 Tab·F6으로 초점을 옮기면 작업 대상도 바뀝니다. 도구 모음·설정·왼쪽 탐색으로 초점이 나가도 마지막 작업 대상 표시는 유지됩니다.

패널 맨 위의 이름이나 연필 아이콘을 눌러 그룹 이름을 바꿉니다. Enter 또는 **저장**으로 확정하고 Esc 또는 **취소**로 되돌립니다. 빈 이름은 기본 패널 이름으로 돌아갑니다. 그룹은 패널 위치에 고정되며 1·2·4분할을 전환하거나 앱을 재실행해도 이름과 폴더 탭을 유지합니다. 실제 폴더의 이름은 바꾸지 않습니다. 상단 **설정**에서 테마와 목록 간격을 바꿀 수 있습니다.

상단 **작업공간**에서 이름을 입력해 현재 배치를 저장하고, 저장한 이름을 눌러 불러옵니다. 같은 이름으로 저장하면 갱신합니다. 배치 전환 전 필요한 현재 배치를 저장하세요. 기록 삭제는 실제 파일을 지우지 않습니다. 테마·즐겨찾기는 모든 작업공간에서 공유합니다.

**Ctrl+T** 새 탭, **Ctrl+W** 탭 닫기, **Ctrl+Shift+T** 닫은 탭 복원, **Ctrl+Tab / Ctrl+Shift+Tab** 다음/이전 탭입니다. 마지막 탭은 닫히지 않습니다. 닫은 탭 복원 기록은 현재 실행 중에만 유지되며, 열린 탭과 마지막 활성 위치는 정상 종료 후에도 복구합니다. 각 탭의 검색어·정렬·선택·커서·스크롤·뒤로/앞으로 이력과 창 위치·크기·최대화 상태도 저장합니다. 없어진 파일은 선택에서 제외하고 목록은 새로 읽습니다. 복원할 선택은 탭당 최대4,096개, 탐색 이력은 방향별128개입니다.

각 패널 제목 오른쪽에서 **자세히·목록·큰 아이콘**을 선택합니다. 패널마다 독립적으로 유지하며 작업공간과 정상 재실행에도 복원합니다. 큰 아이콘은 패널 폭에 맞춰 열 수를 조정하고, 작은 창에서는 타일 높이를 줄입니다. 아이콘 보기의 위·아래 방향키는 한 행, 좌·우는 한 항목씩 이동합니다. **반전** 버튼이나 Ctrl+I는 현재 필터 안의 선택을 뒤집습니다. 주소창 왼쪽 폴더 아이콘을 누르면 상위 경로를 골라 바로 이동할 수 있습니다.

폴더 주소 입력 후 Enter로 이동합니다. 목록에서 Ctrl+A/C/X/V, Enter, Backspace, Delete, F2를 사용할 수 있습니다. 파일을 클릭하거나 대상 패널의 빈 목록 영역을 누른 뒤 복사·붙여넣기할 수 있고, 패널 탭에 포커스가 있어도 Ctrl+V로 현재 폴더에 붙여넣습니다. 복사 완료는 파일 목록이 실제 Windows 클립보드에 기록된 뒤 표시합니다. 같은 폴더에 복사·붙여넣으면 Windows가 중복을 피하는 이름으로 사본을 만들고 원본은 보존합니다. 붙여넣기나 대상을 지정한 패널 복사가 끝나면 실제로 생성된 파일들을 대상에서 선택하고 화면 안으로 스크롤하며 목록에 키보드 포커스를 둡니다. 바로 F2·Enter·다음 복사 등의 작업을 이어갈 수 있습니다. 이름 필터가 결과를 가리면 지워서 표시합니다. 작업 중 다른 화면이나 입력창으로 이동했다면 완료 응답이 포커스를 빼앗지 않습니다.

**복사 대상 선택**은 선택한 파일을 다른 패널의 지정한 탭 폴더로 직접 복사합니다. 일반 **복사/Ctrl+C**처럼 클립보드에 넣는 기능과 구분됩니다. 원본 항목을 선택한 뒤 버튼을 누르고 대상 패널을 고르세요. 그 패널의 **현재 열린 탭**이 먼저 표시되며 다른 탭으로 변경할 수 있습니다. 그룹 이름·패널 번호·위치·탭 번호·전체 경로를 확인한 뒤 **선택한 폴더로 복사**를 누릅니다. 마지막 탭을 자동으로 고르지 않습니다. 확인 전에는 파일과 대상 패널의 탭을 바꾸지 않으며 취소/Esc는 작업을 시작하지 않습니다. 복사 시작 시 선택한 대상 탭을 열고 완료 후 실제 생성 항목을 그 패널에서 선택합니다. 같은 폴더를 다른 패널에도 열어 두어도 명시한 패널이 결과 표시 대상입니다. 1분할에서는 Ctrl+C/V를 사용할 수 있습니다.

Windows 클립보드 기록 응답 후 원본에 **복사/이동** 배지를 표시하고 잘라낸 아이콘을 흐리게 표시합니다. 이동 성공 후 처리한 원본의 표시를 정리하며, 다른 앱이 클립보드를 바꾸면 이전 표시를 해제합니다.

목록에서 `j`를 누르면 j로 시작하는 항목을 선택하고 화면 안으로 스크롤합니다. 같은 키를 빠르게 반복하면 다음 일치 항목으로 순환하고, `j` 다음 `u`처럼 연속 입력하면 접두어로 찾습니다. 방향키·Home·End·Shift+방향키도 지원합니다.

각 패널의 **현재 폴더 검색**은 탭별로 독립적이며, Ctrl+F 또는 F3으로 검색창에 이동합니다. 이름 일부를 입력해 현재 폴더 목록을 즉시 좁힙니다. Esc나 ×로 검색어를 지우고 Enter로 목록에 돌아갑니다. 이 검색은 하위 폴더를 자동 탐색하지 않습니다.

F5/Ctrl+R은 선택을 유지하는 새로고침, Ctrl+L/Alt+D는 주소창, Alt+←/→는 뒤로/앞으로, Alt+↑는 상위 폴더입니다. Backspace는 뒤로 이동합니다. Ctrl+Shift+N은 새 폴더, F6/Shift+F6은 패널 이동, **Ctrl+Shift+F는 통합 검색**입니다. 지원 범위와 차이는 [단축키 목록](docs/shortcuts.md)에 정리했습니다. 하위 폴더 검색은 통합 검색의 선택 폴더 색인을 사용합니다. 파일은 더블클릭하면 Windows 기본 프로그램으로 열립니다.

목록의 **Ctrl+Z**는 이번 실행 중 앱에서 완료한 복사·이동·이름 변경·새 폴더·휴지통 작업을 취소하고, **Ctrl+Y / Ctrl+Shift+Z**는 다시 실행합니다. 최대16단계이며 다른 앱의 작업을 취소하지 않습니다. 입력창에서는 해당 입력창의 텍스트만 되돌립니다. 복사 취소는 생성된 사본을 휴지통으로 옮기며 다시 실행은 그 사본을 복원합니다.

덮어쓰기·폴더 병합·영구 삭제·연결/클라우드 재분석 항목·확인 범위 초과 작업은 실행 취소 기록에서 제외하고 이전 이력도 초기화합니다. 파일 내용 백업은 만들지 않으며, 파일 식별자·크기·수정 시각·하위 목록 메타데이터가 달라졌거나 복원 위치가 점유됐으면 거부합니다. 내용 자체를 비교하는 검사가 아니므로 다른 프로그램의 동시 변경까지 완전히 보호하는 보장은 없습니다. 일부만 처리된 작업은 이력을 초기화합니다. 앱 종료 시 이력은 사라집니다.

왼쪽 **폴더 트리 → 내 PC**에서 드라이브를 펼치세요. 화살표는 펼치기/접기, 이름은 활성 패널에서 열기입니다. **현재 위치 따라가기**를 켜면 활성 탭까지 필요한 상위 폴더만 펼치고 가로·세로 위치를 맞춥니다. 펼친 가지 최대64개와 따라가기·내 PC 상태를 정상 종료 후 복원합니다. 트리의 위/아래·Home/End는 노드 간 키보드 초점을 옮기고 Enter로 엽니다. 숨김 옵션을 따르며 ↻는 가지를 접고 캐시를 다시 읽습니다. 다른 가지의 변경이나 드라이브 연결/해제는 트리 ↻로 갱신합니다. 전체 드라이브를 재귀 탐색하지 않습니다.

파일 목록의 **자동 갱신**은 보이는 패널의 현재 폴더만 Windows 알림으로 감시합니다. 새 목록을 별도 버퍼에서 받아 교체하므로 읽는 동안 선택과 파일 작업 버튼을 유지합니다. 최신 검색어·선택을 기준으로 결과를 합치며, 외부 이름 변경도 선택에 반영합니다. 알림을 지원하지 않는 드라이브나 연결 오류는 상태에 표시하고 F5로 다시 연결할 수 있습니다. 느린 폴더 읽기는 패널의 ×로 취소하고 ↻/F5로 재시도합니다.

파일이나 빈 영역을 우클릭하면 기본 메뉴가 열립니다. **Shift+F10/메뉴 키**도 지원하며 방향키·Tab·Enter·Esc로 조작합니다. 전체 경로 복사는 따옴표로 감싼 경로들을 줄 단위로 넣습니다. **여기서 터미널 열기**는 현재 패널 폴더에서 Windows PowerShell을 실행합니다. Windows 속성과 연결 프로그램 선택은 별도 작업 프로세스에서 엽니다. **연결 프로그램 직접 선택…**은 Windows 파일 선택 창에서 실행 파일(.exe)을 고른 뒤 해당 파일을 인수로 전달합니다. 기본 파일 연결은 바꾸지 않으며 Windows 등록 앱 목록을 표시하는 방식과는 다릅니다. 타사 Shell 확장 메뉴 전체를 호스팅하지는 않습니다.

**일괄 이름**은 최대500개 선택 항목의 이름 본문에 글자 치환·앞/뒤 글자·시작 번호를 적용하고 파일 확장자는 유지합니다. 미리보기를 확인한 뒤 적용하며 중복·예약 이름·기존 이름 충돌은 실행 전에 막습니다. 폴더 이름에도 적용합니다. 작업 도중 외부 변경이나 취소로 일부만 완료될 수 있으며 **작업 기록**에 실제 결과를 표시합니다. 실행 취소는 기존 파일 작업과 같은 검증 조건을 따릅니다.

**작업 기록**은 실행 중 최근32건을 보관하고 항목별 결과는 최대500개·경로 데이터 상한 내에서 표시합니다. 성공 항목과 결과를 알 수 없는 항목은 자동으로 다시 실행하지 않습니다. 재시도는 확인된 미완료 항목에만 적용하고 기존 기록의 재시도 버튼은 소비합니다. 큰 작업은 재시도가 제한되며 폴더의 부분 실패는 선택한 폴더 단위로 확인합니다. 덮어쓰기 판단은 Windows 창을 따르고 재시도 때문에 사용 중인 패널을 전환하지 않습니다. 종료 후 작업 기록은 보존하지 않습니다.

선택 파일을 앱 밖으로 드래그하면 Windows OLE 파일 목록을 전달합니다. 현재는 **복사 전용**이며 원본을 삭제하지 않습니다. 실제 저장·첨부 완료는 받는 프로그램에서 확인합니다. 클라우드 항목은 파일 시스템 속성으로 **온라인 전용/원격·로컬 사용 가능·로컬 보관**을 표시하며 목록에서 내용 다운로드를 요청하지 않습니다. 공급자의 동기화 성공 여부나 인터넷 연결 상태를 이 표시로 단정하지 않습니다.

패널의 **⚙**에서 자세히 보기 열과 아이콘 타일 크기를 설정합니다. 이름 열은 필수이고 너비·보이는 열은 가로 스크롤에 반영합니다. 탭 우클릭의 고정·좌우 이동도 작업공간·정상 재실행에 보존됩니다. 고정 탭은 고정을 해제한 뒤 닫으세요.

트리는 별도 취소 가능한 작업 프로세스에서 한 단계만 읽습니다. 새 가지 요청은 이전 요청을 중단하고 필요한 경우 다시 시도할 수 있습니다. 폴더당 최대1,000개·전체5,000개, DOM 최대60행으로 제한하며 한도·오류를 화면에 표시합니다. 경로 데이터와 조회 시간에도 한도가 있지만, OS I/O의 즉시 반환을 보장하는 시간 제한은 아닙니다. 긴 이름과 깊은 경로는 생략 표시하고 툴팁으로 전체 경로를 확인합니다.

마우스 측면 버튼은 포인터 아래 패널에서 한 단계씩 뒤로/앞으로 이동합니다. 패널 밖에서는 활성 패널을 사용하고, 설정·이름 변경 같은 대화상자가 열렸을 때는 이동하지 않습니다. 제조사 프로그램에서 측면 버튼을 다른 키로 재지정했다면 해당 키 매핑에 따라 달라질 수 있습니다.

## 검색과 성능 범위

**전체 드라이브 실시간 검색**은 C/D/E 초기 색인·추적 상태, C/E 실제 파일 변경과 검색 호스트 종료 여정을 검증했습니다. Windows에서 [전체 드라이브 검증 실행기](scripts/verify-live-search.cmd)로 다시 검사할 수 있습니다. 실행 파일·검사 범위는 [검증 상태](docs/test-summary.md)를 확인하세요. 설치된 Everything의 설정·복원된 의사코드와 SDIR 적용 사항은 [Everything 분석](docs/everything-analysis.md)에 기록했습니다.

검색 창의 **검색 설정**을 열고 사용자 설정의 **통합 검색**에서 **현재 폴더 색인**을 눌러 시작합니다. 파일 내용은 읽지 않습니다. 숨김 항목을 제외하고, 연결 폴더·정션을 재귀적으로 따라가지 않습니다. 상한은 200만 항목·128단계이며, 결과는 먼저 200개를 표시합니다. 검색 결과 시간은 검색 엔진 처리 시간이고 화면 표시나 최초 색인 시간을 포함하지 않습니다. 메모리 표시는 색인 내부 버퍼이며 앱 전체 메모리가 아닙니다.

현재 폴더 색인은 **현재 실행 세션의 스냅샷**입니다. 파일 변경 후 다시 색인해야 합니다. **전체 드라이브 실시간 검색**은 외부 Everything 설치 없이 로컬 NTFS 볼륨의 MFT 파일명·경로를 모으고 기존 USN 저널의 변경분을 추적합니다. 일반 파일 관리자는 권한을 유지하고 검색 전용 프로세스만 Windows UAC 승인을 요청합니다. 전체 볼륨 색인에는 숨김·시스템 이름도 포함될 수 있으며, 파일 내용은 검색하지 않습니다.

드라이브별 초기 색인·변경분 반영·실시간·연결 끊김·오류·상한 상태를 표시합니다. 비NTFS·NAS는 이 고속 색인의 대상이 아니므로 폴더 검색을 이용하세요. USN 저널이 비활성인 드라이브는 이유를 표시하며 저널을 임의로 생성하거나 크기를 늘리지 않습니다. 저널 교체·이력 유실은 해당 볼륨의 초기 색인부터 다시 확인합니다. 색인은 이번 실행 동안 메모리에 유지하며 앱 종료 후 상주 서비스나 영구 검색 DB를 만들지 않습니다. 재시작하면 전체 검색을 다시 시작해야 합니다.

색인 버퍼 예산은 256MiB~2GiB에서 선택하며 변경값은 검색을 다시 시작할 때 적용됩니다. 기본값은1GiB이며 선택한 예산은 이번 실행 중 검색 창을 닫아도 유지합니다. 페이지 반영과 버퍼 확장 중에는 일시 초과할 수 있고, 이 수치는 UI·프로세스 전체 메모리 제한이 아닙니다. 상한에 도달한 범위는 일부 결과로 표시하고 중지하면 검색 프로세스와 색인 메모리를 해제합니다. C/D/E 초기 색인·추적 상태, C/E 실제 파일 변경과 중지·종료 후 검색 호스트 정리를 검증했습니다. 물리 장치 분리와 저널 교체 시험은 별도 환경 확인 대상입니다.

영구 검색 DB, 내용 검색, 썸네일·미리보기, 네트워크 드라이브 전용 최적화는 미구현입니다. 외부 파일 드래그는 복사 전용이며 다른 권한·공급자 조합은 추가 검증이 필요합니다.

Windows의 폴더 목록 열거에 포함된 메타데이터를 재사용해 파일마다 별도 속성 조회를 반복하지 않습니다. 다만 클라우드 공급자 자체의 폴더 열거·파일 열기·복사 지연은 별도로 발생할 수 있습니다. 이번 OneDrive 최상위 폴더 확인에서는 Q-Dir의 멈춤을 재현하지 못했습니다.

폴더 읽기·색인·파일 작업을 UI와 다른 프로세스에서 수행합니다. 읽기 프로세스는 교체·취소할 수 있고, 파일 변경 작업은 Windows 진행 창에서 취소합니다. 덮어쓰기·권한·오류 처리는 Windows Shell이 담당합니다. 여러 항목 작업을 취소하거나 오류가 나면 일부만 처리됐을 수 있습니다. 파일 작업 중 앱을 닫아도 이미 시작된 Windows 작업은 계속될 수 있습니다.

이 버전은 첫 사용 검증용입니다. 실제 PC에서의 메모리·입력 지연과 대형 폴더 측정 결과는 [검증 기록](docs/verification.md)에 구분해서 적습니다.

사용자 여정별 기준과 미확인 항목은 [사용자 여정 검증표](docs/user-journeys.md)에 기록합니다.

## 빌드와 검증

Windows: Rust MSVC 1.94 이상과 Visual Studio C++ Build Tools, WebView2 Runtime을 준비합니다.

```powershell
.\scripts\build-windows.ps1 -Test
.\dist\SDIR.exe
```

빌드 출력은 기본적으로 `%LOCALAPPDATA%\SDIR-build\target`을 사용하며, `CARGO_TARGET_DIR`로 바꿀 수 있습니다. `Cargo.lock`과 goz-core commit을 고정했습니다. Dioxus CLI 없이 Cargo로 빌드합니다.

Windows UI 검증에는 Node.js 22 이상이 추가로 필요합니다. 기본 UI 검사는 사용자 파일·클립보드를 변경하지 않고 임시 폴더와 분리 프로필에서 실행합니다. 별도의 클립보드 여정 검사는 클립보드를 백업한 뒤 일시 사용하고 복원합니다. 증거와 임시 폴더 경로를 `docs/task-id/sdir-first-app`에 남깁니다.

```powershell
.\scripts\smoke-windows.ps1
.\scripts\smoke-windows.ps1 -Large  # 실제 10만 파일 생성; 임시 폴더 유지
node .\scripts\preferences-smoke.mjs .\dist\SDIR.exe  # 그룹·테마·간격·재실행 여정
powershell.exe -STA -File .\scripts\clipboard-journey.ps1  # 실제 키·클립보드·파일 결과; 기존 클립보드 백업/복원
```

Linux/WSL에서는 GUI를 제외한 코어·프로세스 통신을 검사할 수 있습니다.

```bash
cargo test --locked --all-targets
```

### 통합 검색의 사용자 설정

설정 → 통합 검색에서 입력 즉시 검색, 검색창 전체 선택, 검색을 열 때 초점 이동과 색인 메모리 상한을 지정할 수 있습니다. 입력 즉시 검색을 끄면 Enter 또는 검색 버튼으로 실행합니다. 선택값은 재실행·포터블 이동 뒤에도 유지하고 검색 설정만 초기화할 수 있습니다. [검색 설정 안내](docs/search-settings.md)를 참고하세요.
