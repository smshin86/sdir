# 개발·테스트 저장소 정리

2026-11-16. 소유를 확인한 테스트 데이터와 교체된 개발 산출물을 정리했다.

| 대상 | 조치 |
|---|---|
| 예전 임시·측정 폴더 | 246개 삭제, 파일 논리 크기 약4.50GiB. 측정 폴더에는 이번 전후 비교용 복사본도 포함 |
| 예전 실행 파일·ZIP·심볼·덤프 | 20개, 약163.7MiB 삭제 |
| 이번 작업의 교체된 실행 파일 | 7개, 약61.5MiB 삭제 |
| 이전 Linux 디버그 캐시 | 약814MiB 회수 |
| 최종 검증 후 Windows/Linux 디버그 캐시 | 각각 약1.66GiB / 251MiB 회수. 이번 빌드에서 생성된 캐시이므로 기존 자료 회수량과 구분 |
| 프로젝트 안의 트리 시험 폴더 | 소유 파일 해시를 확인한6개 삭제, 이후 Tree 시험은 종료 시 자체 삭제 |

새 여정 실행기는 한 실행 폴더에 임시 프로필·대량 파일을 모으고 성공·실패 후 회수한다. 실제 파일 이동이 필요한 E: 트리 여정도 별도로 자기 폴더를 정리하도록 바꿨고 삭제 성공을 검증했다. 활성 프로세스 데이터·복원되지 않은 암호화 클립보드 백업·소유가 확정되지 않은 자료는 자동 삭제하지 않는다. 0바이트의 잠긴 이전 테스트 디렉터리는 보존했다. 사용자 앱은 강제 종료하지 않았다.

최종 후보·이전 배포·비교 기준 실행 파일·검증 기록은 보존했다. 실제 NTFS 권한 승인 시험에서 수정이 필요할 경우를 위해 현재 release 의존성 캐시 약1.4GiB는 유지한다. 전역 Rust/Node 캐시와 다른 프로젝트는 정리하지 않았다.

파일 논리 크기·빌드 캐시 추정 할당량과 드라이브 전체 빈 공간 증감을 합쳐서 보고하지 않는다. 파일 시스템 메타데이터와 다른 프로세스의 활동 때문에 차이가 난다. 원시 삭제 영수증은 이 PC의 `docs/task-id/performance-optimize`에 남겼다.
