# 참고 프로젝트의 장점과 SDIR 적용

참고 대상은 기존에 검토한 [MTT File Manager](https://github.com/MTTamurex/MTT-File-Manager-RUST/blob/78ad0d19082d61fb54f48131c2aae53439fdba88/README.md)와 내장 검색 엔진인 [goz-core](https://github.com/mustafaahci/goz/tree/78ca353b8c0b227e47217c33c25d37fcff025e33/crates/goz-core)다. MTT 항목은 해당 고정 커밋의 문서·기존 소스 조사에 근거하며 MTT 앱의 실제 실행 검증을 의미하지 않는다. MTT의 UI 소스는 복사하지 않고 현재 Dioxus 상태 모델에 맞춰 구현한다.

| 확인한 장점 | SDIR에서 사용할 흐름 | 구현과 검증 |
|---|---|---|
| 패널별 독립 보기와 세션 복원 | 각 패널에서 자세히·목록·큰 아이콘을 선택하고 작업공간/재실행 후 유지 | `Pane.view`, `Settings.pane_views`, `views-smoke.mjs` 자동 통과 |
| Grid/Details 화면의 가상화 | 아이콘도 전체 폴더를 DOM으로 만들지 않고 현재 화면 근처만 렌더링; 열 수에 맞춰 방향키 이동 | `ViewGeometry`, 크기 관찰자는 패널당1개·최대4개, 자세히/목록은 화면 높이에 맞춘 행·아이콘최대512개; 새 썸네일 읽기 없음 |
| Smart address bar의 경로 계층 이동 | 주소창 폴더 아이콘에서 상위 경로 메뉴를 열고 원하는 조상 폴더로 바로 이동; 직접 주소 입력 유지 | `views-smoke.mjs`에서 실제 경로와 이동 후 파일 목록 확인 |
| 복사/잘라내기 피드백 | Windows 기록 응답 뒤 복사/이동 배지, 잘라낸 아이콘 흐림, 이동 성공 후 표시 정리 | 실제 OS 클립보드 왕복과 `navigation-smoke.mjs` |
| 선택 반전 등 선택 제어 | 목록 하단 반전 버튼 또는 Ctrl+I; 필터 안의 항목만 대상 | 모델 테스트와 실제 키 입력·전체 선택 수 확인 |
| 상한을 둔 목록·검색 작업 | 최신 요청만 처리하고 이전 폴더 응답을 폐기, 별도 작업 프로세스와 가상 목록 유지 | 기존 worker/취소 회귀와 새 보기·복사 후 화면 흐름 통합 검사 |

사용자 지적으로 추가한 작업 후 흐름은 **복사·이동 완료 → Windows가 보고한 실제 최종 경로만 선택 → 대상 보기 안으로 스크롤 → 목록 키보드 포커스 → 바로 이름 변경/이동**이다. 같은 폴더 사본은 추측한 원본 이름으로 선택하지 않는다. 사용자가 작업 중 다른 패널·폴더나 입력창으로 이동하면 늦은 완료 응답이 화면을 빼앗지 않도록 사용자 입력 세대와 폴더 요청 세대를 확인한다.

MTT의 Miller's Columns, 핀 탭, 열 편집, Shell 메뉴, 미디어 미리보기, 클라우드 상태 배지, 전체 드라이브 실시간 색인은 이번 적용 기능으로 표시하지 않는다. 이들은 실제 환경 검증이나 별도 파일/장치 접근 경로가 필요하다. 현재 아이콘 보기는 파일/폴더 아이콘이며 이미지·영상 썸네일 뷰어는 아니다.

이전 보기 기능 적용 버전 기준 전체53개 회귀 검사 묶음과 새 보기·참고 기능6개 묶음(53개 안에 포함)이 통과했다. 실제 결과·클립보드·설정·화면 상태를 함께 확인했고, 10만 파일 탐색13개 묶음과 읽기 취소·복구4개 묶음도 별도로 통과했다. 산출물 식별은 `docs/task-id/paste-reveal/artifact.json`을 따른다.

현재 단축키·전체 세션·파일 이력·포터블 배포의 검증 결과는 [최신 검증 기록](verification.md)의 마지막 절과 `docs/task-id/windows-basics/artifact.json`을 따른다.
