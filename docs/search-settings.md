# 통합 검색 설정

상단 **설정 → 통합 검색**을 엽니다. 설정은 바로 저장되며 앱을 다시 열거나 포터블 폴더를 이동해도 유지합니다.

**현재 폴더 색인**이나 **전체 드라이브 실시간 검색**을 누른 뒤, 설정을 닫고 통합 검색 창에서 검색어를 입력합니다. 색인 범위와 진행 상태를 확인하거나 색인을 중지하려면 같은 설정 섹션을 엽니다.

| 설정 | 사용 방법 |
|---|---|
| 입력 즉시 검색 | 켜면 입력에 맞춰 검색합니다. 끄면 검색어를 완성한 뒤 Enter 또는 검색 버튼을 누릅니다. 검색어를 먼저 입력하고 색인을 만들더라도 수동 모드에서는 제출 전 검색하지 않습니다. |
| 검색창에 초점이 들어오면 전체 선택 | 처음 검색창으로 이동할 때 기존 검색어를 선택해 바로 바꿀 수 있습니다. 이미 초점이 있는 검색창을 다시 클릭하면 원하는 위치에서 편집할 수 있습니다. |
| 검색 패널을 열 때 검색창으로 이동 | 통합 검색 버튼을 눌렀을 때의 초점 이동을 선택합니다. 끈 상태에서도 Ctrl+Shift+F는 검색창으로 이동합니다. |
| 전체 검색 색인 메모리 상한 | 256 MiB~2 GiB에서 선택합니다. 사용자 설정에서 변경합니다. 실행 중인 색인의 상한은 검색을 다시 시작할 때 바뀝니다. 이 값은 앱 전체 메모리 제한이 아닙니다. |
| 검색 설정 초기화 | 위 검색 설정만 기본값으로 되돌립니다. 폴더·탭·패널 이름과 테마는 보존합니다. |

이 설정은 **통합 검색**에 적용합니다. 패널의 Ctrl+F는 현재 폴더 목록을 기존처럼 입력 즉시 좁힙니다. 전체 드라이브 검색을 실행한 뒤에는 수동 모드에서도 제출한 검색어에 해당하는 파일 변경을 계속 반영합니다.

기본값은 입력 즉시 검색·전체 선택·검색을 열 때 초점 이동이 켜짐, 색인 상한은 1 GiB입니다. 검색·드라이브 정책은 프로필 설정에서 복원합니다. 현재 폴더 색인은 실행 중에 유지합니다.

통합 검색창의 왼쪽 경계를 끌거나 경계에 키보드 초점을 두고 좌우 방향키를 눌러 너비를 바꿉니다. 확대 버튼은 패널과 폴더 트리가 쓰던 작업 영역까지 검색에 사용합니다. 검색 결과를 선택하면 **결과를 열 패널**의 새 탭에서 해당 폴더를 열고 파일을 선택합니다.

## Windows 색인 서비스

전체 드라이브 실시간 검색을 자주 사용한다면 SDIR 색인 서비스를 따로 설치할 수 있습니다. 설치 시 관리자 승인을 하고 서비스를 사용할 Windows 계정을 지정합니다. 설치 뒤 해당 계정에서 **전체 드라이브 실시간 검색**을 누르면 Windows가 서비스를 시작합니다.

서비스는 지정한 계정에 고정 로컬 NTFS 드라이브의 파일 이름과 경로를 검색할 권한을 부여합니다. 처음 전체 드라이브 색인을 만들면 서비스가 드라이브별로 보호된 색인 파일을 저장합니다. 다음에 SDIR을 열면 저장한 색인을 읽고 NTFS 변경 저널에서 이후 변경 사항을 반영합니다. 저장한 색인을 사용할 수 없는 드라이브는 다시 색인합니다. 설정에서 드라이브별 복원·저장 상태를 확인할 수 있습니다.

**중지**를 누르면 다음에 앱을 열 때 자동 복원을 시작하지 않습니다. 서비스가 설치되지 않은 환경에서는 수동으로 관리자 인증을 하고 전체 드라이브를 색인할 수 있습니다. 이 방식은 현재 실행에서 색인을 유지하며, 앱을 열 때는 관리자 인증 창을 띄우지 않습니다.

## 창 닫기와 Windows 시작

**설정 → 창과 시작**에서 **X로 닫을 때 트레이에 유지**를 켜면 창을 닫아도 색인과 파일 변경 추적이 계속됩니다. 트레이 아이콘을 누르면 기존 창이 열리고, 트레이 메뉴의 **종료**를 선택하면 프로그램이 종료됩니다. **Windows 로그인 시 실행**을 켜면 로그인할 때 SDIR이 열립니다. 두 옵션의 기본값은 꺼짐입니다.

## 드라이브별 검색 결과 범위

전체 드라이브 실시간 검색은 Windows 설치 볼륨의 `WinSxS`와 하위 항목을 기본으로 숨깁니다. 해당 항목을 보려면 **설정 → 통합 검색 → 드라이브 색인 → Windows 구성 요소(WinSxS) 표시**를 켭니다. 드라이브마다 저장한 포함·제외 경로도 계속 적용합니다.

설정 → 통합 검색 → 드라이브 색인에서 지원되는 볼륨의 결과 범위를 편집합니다. 포함·제외 경로는 볼륨 루트 기준 상대 경로이며 한 줄에 하나씩 입력합니다. 초안은 저장을 누르기 전까지 설정이나 디스크에 반영되지 않습니다. 비워 둔 포함 목록은 모든 경로를 허용하고, 제외 경로가 포함보다 우선합니다. 이 범위는 색인된 볼륨 안의 검색 결과를 필터링하며 색인 수집 범위를 줄이지 않습니다.

연결되지 않은 볼륨의 저장 정책은 볼륨 GUID와 함께 표시됩니다. 색인 서비스는 연결이 끊긴 드라이브의 캐시도 기본적으로 보존합니다.
