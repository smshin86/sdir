[검색 설정 안내](search-settings.md)는 사용법을, [Everything 분석](everything-analysis.md)은 이전 엔진 분석과 이번 인터페이스 설정 반영을 구분한다. 설정값만 저장하며 파일 색인 자체는 실행 세션 동안만 유지한다. 전체 검색 상한 변경은 다음 색인 시작 때 적용하고, 재실행 시 색인을 자동 시작하거나 관리자 인증을 요청하지 않는다.

두 실제 전체 검색 실패와 당시 소스를 `docs/task-id/search-preferences/escalation`에 보존했다. 검토에서는 일반 데스크톱의 정확한 소유 창·캡션을 확인하고, 새 초안 뒤 이전 검색에 해당하는 파일을 변경해 늦은 스트리밍 응답을 검사하도록 요구했다. 관리자 인증 가능 여부에 대한 실제 응답 전에는 같은 UAC 검증을 반복하지 않는다. 미실행 항목은 통과로 합산하지 않는다.

현재 배포 중인 이전 실행 파일은 Windows53/Linux45·127개 기본 여정·실제 전체 NTFS8개·포터블4개를 통과했다. 그 증거는 `docs/task-id/live-search/artifact-20261117.json`과 [검증 기록](verification.md)에 남긴다. 이전 후보의 검증을 현재 후보로 소급하지 않는다.

실제 장치 분리·저널 교체·클라우드 공급자 장애·NAS 지연·실제 IME·접근성·다중 DPI는 별도 환경 확인 대상이다. 상주 트레이·영구 검색 DB·서비스 설치·파일 열기 정책 변경은 이번 설정 반영 범위가 아니다.
