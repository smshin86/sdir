# Windows 설치형

Windows x64에서 무인 새 설치, 설치된 앱 실행, 같은 배포본 재설치, 제거를 확인했다. 재설치 때 프로그램을 교체하고 사용자 설정과 테스트 파일을 보존했다. 제거 후에도 사용자 설정을 보존했다. 검증 환경은 스마트 앱 컨트롤이 꺼진 Windows이며, 설치 EXE는 미서명이다.

설치형은 Windows x64 사용자별 설치다. 기본 위치는 `%LOCALAPPDATA%\Programs\SDIR`이며 시작 메뉴와 프로그램 제거 항목을 등록한다. 바탕 화면 바로가기는 설치 화면에서 선택한다. 공유 Microsoft Edge WebView2 Runtime이 필요하며, 런타임이 없을 때는 설치를 중단하고 안내한다.

재설치에서는 기존 설치의 등록 정보와 파일 목록을 확인하고, SDIR이 설치한 프로그램 파일을 교체한다. 이전 버전의 설치 파일 목록에 포함된 불필요한 파일도 정리한다. 설치 폴더 전체를 무조건 삭제하는 방식은 사용하지 않는다. 사용자 설정과 추가로 넣은 파일은 보존하며, 출처를 확인할 수 없는 설치 폴더나 변경된 프로그램 파일은 확인 없이 덮어쓰지 않는다.

SDIR 또는 관련 작업 프로세스가 실행 중이거나 교체할 파일이 잠겨 있으면 재설치를 중단한다. 프로그램을 자동으로 강제 종료하지 않는다. 사용자가 SDIR을 정상 종료하고 다시 설치한다. 취소·실패 시 기존 프로그램 파일과 설치 상태의 복원을 검증하며, 강제 종료·정전 중 복구는 현재 보장 범위에 포함하지 않는다.

설치형의 기본 설정 위치는 `%LOCALAPPDATA%\SDIR`이다. 프로그램 제거 후에도 개인 설정은 보존한다. 포터블은 `portable.flag`가 있는 폴더의 `data`를 사용하므로 설치형과 설정 위치가 다르다. `SDIR_PROFILE_DIR` 환경 변수가 있으면 해당 경로가 우선한다.

설치형과 포터블은 같은 실행 파일을 사용한다. 배포 폴더 `dist/2026-11-20-search-ux`에 `SDIR-windows-x64-setup.exe`, `SDIR-windows-x64-portable.zip`, `SHA256SUMS.txt`를 제공한다.
