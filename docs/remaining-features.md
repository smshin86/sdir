# 남은 기능과 확인 범위

2026-11-16 탐색기 기본 편의 확장 기준이다. 구현·실제 검증 결과는 [검증 기록](verification.md)과 [사용자 여정](user-journeys.md)에 구분한다.

| 구분 | 현재 없는 기능 |
|---|---|
| 탐색기 기본 편의 | 타사 확장을 포함한 Windows Shell 메뉴 전체, F4 주소 기록 메뉴, Ctrl+휠 크기 변경 |
| 파일 보기 | 이미지·영상 썸네일, 내용 미리보기, 선택 여러 항목의 통합 속성 |
| 검색 | 모든 드라이브 MFT/USN 실시간 색인, 영구 검색 DB, 파일 내용 검색; 현재는 선택 폴더의 실행 중 스냅샷 |
| 파일 작업 | 외부 드래그의 이동 모드, 덮어쓰기·병합·영구 삭제 실행 취소, 종료 후 작업 기록 유지, 일시 정지/재개, 폴더 비교·동기화 |
| 트리 | 드라이브 연결/해제 자동 감지, 모든 가지 변경의 자동 반영, Shell 가상 폴더 전체 표현; 현재 폴더 목록은 자동 갱신하고 다른 트리 가지는 ↻ 사용 |
| 배포 | 설치형 패키지, 코드 서명, 자동 업데이트 |

현재 경로 트리 따라가기·펼침 복원·키보드 순회, 기본 우클릭 메뉴·연결 프로그램·경로 복사·현재 폴더 터미널, 파일 목록 자동 갱신, 일괄 이름 변경과 충돌 미리보기, 세션 작업 기록·미완료 재시도, 복사 전용 외부 드래그, 탭 고정·순서 변경, 열 표시·너비·아이콘 타일 크기 설정을 추가했다. 완료 판정은 최종 실행 파일로 수행한 여정 결과를 따른다.

| 환경별 추가 확인 | 확인이 필요한 내용 |
|---|---|
| 클라우드·NAS | 실제 공급자별 온라인 전용 다운로드, 인증 만료·오프라인·권한 거부, 네트워크 지연 중 대용량 복사 취소·부분 완료 |
| 외부 드래그 | 다른 앱 권한·공급자·장치 조합; 복사 전용이며 최종 저장 결과는 수신 프로그램 책임 |
| 입력·접근성 | 실제 한글 IME, 화면 읽기 프로그램, 다중 모니터·DPI 이동, 제조사에서 재지정한 마우스 버튼 |
| 성능 | 동일 폴더·PC에서 Q-Dir과 비교한 메모리·시작 시간·네트워크 지연 실측; WebView2 포함 전체 비용을 구분해서 측정 |

클라우드 표시는 파일 시스템 속성에 근거한 보관 상태다. 동기화 성공이나 인터넷 연결을 의미하지 않는다. 실제 클라우드 계정의 네트워크 장애까지 로컬 대역 검사로 통과했다고 기록하지 않는다. 썸네일·미리보기·전체 드라이브 색인은 별도의 I/O·메모리 검증 후 확장한다.


## 이번 추가 요청의 진행 상태

현재 766B 실행 파일은 127개 기본 여정과 실제 관리자 인증 후 전체 NTFS 검색 8개 여정이 통과했다. C/D/E Live와 C/E 실제 파일 변경·중지·정상/비정상 종료의 검색 호스트 해제를 확인했다. 물리 장치 분리·저널 교체는 별도 실제 환경 확인 대상이다. Everything REA 분석에서 확인한 백그라운드 I/O·30초 오류 재시도를 반영했다. 비NTFS/네트워크 자동 추적·영구 검색 DB·앱 종료 후 상주 검색은 별도 미구현 범위다. 이전 성능 확인 항목은 [실측 보고서](performance-improvement.md)로 대체한다.
