# SDIR 단축키 지원 범위

Windows 탐색기에서 자주 쓰는 키를 지원한다. 모든 탐색기 단축키를 구현한 상태는 아니다. 목록 또는 패널에 포커스를 둔 경우의 동작이며, 주소·검색·이름 입력창의 텍스트 편집은 파일 조작과 분리한다.

| 키 | 동작 |
|---|---|
| Ctrl+C / X / V | 파일 복사 / 잘라내기 / 붙여넣기 |
| Ctrl+A / Ctrl+I | 현재 필터 안 전체 선택 / 선택 반전 |
| 방향키 / Home / End / PageUp / PageDown | 항목·처음·끝·페이지 이동. Shift로 범위 선택 |
| Ctrl+방향키 / Space·Ctrl+Space | 기존 선택을 유지하며 커서 이동 / 커서가 있는 항목만 선택 또는 해제 |
| 문자 연속 입력 | 이름 접두어 선택; 같은 문자 반복으로 순환 |
| Shift+F10 / 메뉴 키 | 파일/빈 영역의 기본 우클릭 메뉴 |
| 방향키 / Home / End / Tab (기본 메뉴) | 메뉴 항목 이동; Enter 실행, Esc 닫기 |
| 위/아래 / Home / End (폴더 트리) | 노드 초점 순회; Enter 열기, 좌/우 접기·펼치기 |
| Enter | 기본 프로그램으로 열기 또는 폴더 이동 |
| F2 | 한 항목은 목록에서 이름 편집. 여러 항목은 확장명을 유지하며 공통 이름에 번호를 붙이기 |
| Delete / Ctrl+D | 확인 후 휴지통 이동 |
| Shift+Delete | 확인 후 영구 삭제. 실행 취소 불가 |
| Ctrl+Shift+N | 새 폴더 |
| Ctrl+Z | 앱에서 완료한 지원 파일 작업 실행 취소 |
| Ctrl+Y / Ctrl+Shift+Z | 파일 작업 다시 실행 |
| Alt+Enter | Windows 속성. 다중 선택은 통합 속성. 선택이 없으면 현재 폴더 속성 |
| Alt+P / Alt+Shift+P | 미리보기 / 상세 정보 창 |
| Ctrl+Shift+C | 선택한 항목의 전체 경로 복사 |
| Alt+← / Alt+→ / Backspace | 뒤로 / 앞으로 / 뒤로 |
| Alt+↑ | 상위 폴더 |
| 마우스 측면 X1 / X2 | 포인터 아래 패널의 뒤로 / 앞으로; 패널 밖은 활성 패널 |
| Ctrl+L / Alt+D | 주소창 선택 |
| F4 | 주소창과 최근 경로 기록 열기. 방향키로 선택, Enter로 이동 |
| F5 / Ctrl+R | 새로고침, 아직 존재하는 선택과 스크롤 복원 |
| Ctrl+F / F3 | 현재 폴더와 하위 폴더에서 이름 검색 |
| Ctrl+E | 해당 패널 현재 목록 이름 필터 |
| Ctrl+Shift+F | 선택 폴더 색인 기반 통합 검색 |
| Enter / Esc (패널 검색창) | 목록으로 복귀 / 검색어 지우고 목록으로 복귀 |
| Ctrl+T / Ctrl+W / Ctrl+Shift+T | 탭 추가 / 닫기 / 닫은 탭 복원 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 |
| Ctrl+1…9 | 현재 패널의 해당 번호 탭 |
| F6 / Shift+F6 | 폴더 트리·도구·탭·주소·목록 초점 순회 |
| Ctrl+F6 / Ctrl+Shift+F6 | 다음 / 이전 패널의 목록 |
| Ctrl+N | 현재 경로를 독립 SDIR 창에서 열기 |
| F11 | 전체 화면 전환 |
| Ctrl+Shift+E | 현재 경로를 왼쪽 폴더 트리에 표시 |
| Ctrl+Shift+1~8 | 아주 큰·큰·보통·작은 아이콘 / 목록 / 자세히 / 타일 / 내용 |
| Ctrl+휠 | 마우스 아래 패널의 아이콘 보기 단계 조절 |
| Ctrl+숫자 키패드 + | 자세히 보기의 표시 열을 내용에 맞춤 |

탭은 패널별 16개이며 고정 탭은 닫지 않는다. 1분할에서 마지막 탭을 Ctrl+W로 닫으면 해당 창을 닫는다. 여러 패널을 열었을 때는 각 패널의 마지막 탭을 유지한다. 탭 우클릭으로 고정·해제·좌우 순서 변경을 할 수 있다. 닫은 탭과 파일 실행 취소 기록은 현재 실행 중에만 유지한다. 입력창의 Ctrl+Z/Y는 각 입력창의 텍스트 이력에 적용한다. 파일 실행 취소의 제외 범위는 [README](../README.md)를 따른다.

SDIR 내부에서 Alt 또는 Ctrl+Shift를 누른 채 파일을 드래그하면 대상 폴더에 Windows 바로 가기를 만든다. 외부 앱에서 SDIR로 드롭하면 복사한다. SDIR에서 이동을 지원하는 외부 앱으로 끌 때는 SDIR 창을 벗어나기 전에 Shift를 누르고 놓을 때까지 유지한다.
