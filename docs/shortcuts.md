# SDIR 단축키 지원 범위

Windows 탐색기에서 자주 쓰는 키를 지원한다. 모든 탐색기 단축키를 구현한 상태는 아니다. 목록 또는 패널에 포커스를 둔 경우의 동작이며, 주소·검색·이름 입력창의 텍스트 편집은 파일 조작과 분리한다.

| 키 | 동작 |
|---|---|
| Ctrl+C / X / V | 파일 복사 / 잘라내기 / 붙여넣기 |
| Ctrl+A / Ctrl+I | 현재 필터 안 전체 선택 / 선택 반전 |
| 방향키 / Home / End / PageUp / PageDown | 항목·처음·끝·페이지 이동; Shift로 범위 선택 |
| 문자 연속 입력 | 이름 접두어 선택; 같은 문자 반복으로 순환 |
| Shift+F10 / 메뉴 키 | 파일/빈 영역의 기본 우클릭 메뉴 |
| 방향키 / Home / End / Tab (기본 메뉴) | 메뉴 항목 이동; Enter 실행, Esc 닫기 |
| 위/아래 / Home / End (폴더 트리) | 노드 초점 순회; Enter 열기, 좌/우 접기·펼치기 |
| Enter / F2 | 기본 프로그램으로 열기 또는 폴더 이동 / 이름 변경 |
| Delete / Ctrl+D | 확인 후 휴지통 이동 |
| Ctrl+Shift+N | 새 폴더 |
| Ctrl+Z | 앱에서 완료한 지원 파일 작업 실행 취소 |
| Ctrl+Y / Ctrl+Shift+Z | 파일 작업 다시 실행 |
| Alt+Enter | 선택 첫 항목의 Windows 속성; 선택이 없으면 현재 폴더 속성 |
| Alt+← / Alt+→ / Backspace | 뒤로 / 앞으로 / 뒤로 |
| Alt+↑ | 상위 폴더 |
| 마우스 측면 X1 / X2 | 포인터 아래 패널의 뒤로 / 앞으로; 패널 밖은 활성 패널 |
| Ctrl+L / Alt+D | 주소창 선택 |
| F5 / Ctrl+R | 새로고침, 아직 존재하는 선택과 스크롤 복원 |
| Ctrl+F / Ctrl+E / F3 | 해당 패널 현재 폴더 이름 필터 |
| Ctrl+Shift+F | 선택 폴더 색인 기반 통합 검색 |
| Enter / Esc (패널 검색창) | 목록으로 복귀 / 검색어 지우고 목록으로 복귀 |
| Ctrl+T / Ctrl+W / Ctrl+Shift+T | 탭 추가 / 닫기 / 닫은 탭 복원 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 |
| Ctrl+1…9 | 현재 패널의 해당 번호 탭 |
| F6 / Shift+F6 | 다음 / 이전 패널의 목록 |
| Ctrl+Shift+2 / 5 / 6 | 큰 아이콘 / 목록 / 자세히 |

탭은 패널별16개이며 마지막 탭과 고정 탭은 닫지 않는다. 탭 우클릭으로 고정·해제·좌우 순서 변경을 할 수 있다. 닫은 탭과 파일 실행 취소 기록은 현재 실행 중에만 유지한다. 입력창의 Ctrl+Z/Y는 각 입력창의 텍스트 이력에 적용한다. 파일 실행 취소의 제외 범위는 [README](../README.md)를 따른다.

Shift+Delete의 영구 삭제, F4 주소 기록 메뉴, Ctrl+휠 아이콘 크기 조절, Ctrl+Shift+1/3/4/7/8/9의 추가 보기, 선택 여러 항목의 통합 속성은 아직 제공하지 않는다. Shift+Delete도 현재는 일반 휴지통 확인으로 처리한다. Windows 탐색기의 모든 키가 동일하다고 안내하지 않는다.
