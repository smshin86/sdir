SDIR Windows 사용자별 설치 안내
================================

이 설치 프로그램은 현재 Windows 사용자 계정의
%LOCALAPPDATA%\Programs\SDIR 에만 설치합니다. 관리자 권한, 서비스,
시작 프로그램 등록, 재부팅 또는 실행 중인 SDIR 종료를 요청하지 않습니다.

시작 메뉴 바로 가기를 만들며, 바탕 화면 바로 가기는 선택 사항입니다.
설치가 끝난 뒤 앱 실행은 선택 사항입니다. 자동 설치에서는 앱을 실행하지
않습니다.

Microsoft Edge WebView2 Evergreen Runtime이 필요합니다. 설치 프로그램은
Microsoft가 문서화한 제품 GUID와 pv 버전을 확인합니다. 런타임이 없으면
설치를 중단하고 Microsoft의 공식 설치 안내를 표시합니다. 런타임이나
시스템 설정을 대신 설치하거나 변경하지 않습니다.

설치 경로에 portable.flag가 있거나 이전 SDIR 설치 소유권을 확인할 수
없으면 파일을 변경하지 않고 중단합니다. 확인할 수 있는 설치의 프로그램
파일만 같은 드라이브의 임시 격리 폴더로 옮긴 뒤 교체합니다. 설정, 탭,
작업공간, 검색 설정, data, 알 수 없는 파일은 설치·업그레이드·제거에서
보존합니다. 실행 중인 앱·작업 프로세스나 외부 잠금이 확인되면 먼저
프로그램을 정상 종료하거나 잠금을 해제한 뒤 다시 시도하세요.

제거는 Windows의 설치된 앱 목록에 등록된 SDIR 항목에서 시작할 수 있습니다.
제거 확인을 취소하면 제거를 시작하지 않습니다. 제거 후에도 사용자 설정과
data는 남습니다. 설정을 지우려면 앱을 제거한 뒤 사용자가 직접 정리해야 합니다.

이 파일은 설치 프로그램에 포함되는 설치형 사용 안내입니다. 설치·업그레이드·
제거 흐름은 이 안내를 따르세요. 함께 설치되는
docs/distribution-portable-reference.md는 과거 포터블 배포 안내서이며,
설치형의 현재 절차를 설명하는 문서가 아닙니다.

포터블 ZIP과 설치형은 함께 사용할 수 있습니다. 포터블 폴더를 설치 경로로
선택하지 마세요. 포터블 설정을 설치형에서 쓰려면 과거 포터블 안내서의
수동 이전 절차에 따라 settings.json만 복사하고, 대상 파일이 이미 있으면
덮어쓰지 마세요. 원본 settings.json은 삭제하지 마세요.
